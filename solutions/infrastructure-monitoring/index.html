Infrastructure Monitoring

One operational view of servers, network equipment, and the services that run on them.

Core features

Device coverage

Monitors servers, network equipment, and services together.

Up and down checks

Tests reachability and how long a service takes to answer.

Host metrics

Collects CPU, memory, disk, and network-interface numbers.

Status board

Shows the estate in one view: up, degraded, or down.

On-call alerts

Sends the failure to the people who need to act.

Outage history

Records when something failed and when it recovered.
