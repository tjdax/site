Software Web Firewall

A software web firewall that inspects requests and blocks attacks before they reach the application. No dedicated appliance is required.

Core features

Request inspection

Looks at the method, URL, headers, and body of each web request.

Attack blocking

Stops SQL injection, cross-site scripting, command injection, and path traversal.

Custom rules

Add allow, block, and exception rules for your own applications.

Rate limits

Slows or blocks clients that send too many requests or repeat an attack.

Allow and deny lists

Trust known sources and refuse known bad addresses or URLs.

Logs and alerts

Records the request that matched a rule and raises an alert.
