Solutions / Document Encryption

Document Encryption

Document encryption that locks files so only authorized people can open them, including after the file has been copied or shared.

Core features

File encryption

Encrypts a document before it is stored or sent.

Authorized open

Only people with permission can decrypt and read it.

Organization keys

Keys stay under your control, not in the clear inside the file.

Policy

Sets access by person, group, or document.

Still encrypted when shared

A forwarded copy stays encrypted, so sending the file does not make it readable.

Open record

Keeps a record of who opened a protected document.
