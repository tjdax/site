Load Balancer

A software load balancer that shares traffic across servers so a service stays fast when one machine is busy or down.

Core features

Traffic distribution

Sends each request to a server in the pool by round robin, least connections, or weight.

Health checks

Stops sending traffic to a server that fails its check, and brings it back when it recovers.

Session persistence

Keeps a user on the same server when the application needs it.

Graceful drain

Moves traffic off a server before maintenance, without dropping the service.

HTTP and TCP

Balances web applications and plain TCP services.

Failure handling

Keeps the service available when a single node fails.
