Real-time Interpretation

A live interpretation program for meetings and conversation. It translates speech while people are still talking.

Core features

Speech capture

Listens to spoken audio and turns it into text.

Live translation

Translates the speech while the speaker continues.

On-screen captions

Shows the translation as text the room can read.

Spoken output

Plays the translation aloud, not only as text.

Running transcript

Keeps the conversation so it can be read after the meeting.

Conversation use

Built for live talk, rather than for translating a finished document.
