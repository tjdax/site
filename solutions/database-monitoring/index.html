Database Monitoring

Live database monitoring for health, capacity, and the queries that slow the system down.

Core features

Health metrics

Watches connections, CPU, locks, and free space.

Slow queries

Finds statements that take too long or do too much work.

Blocking sessions

Shows a session that is holding others up.

Alerts

Raises an alert when the database is short of space, connections, or time.

Trends

Keeps history so a slow change is visible before it becomes an outage.

Query detail

Points at the statement behind the symptom, not only the symptom.
