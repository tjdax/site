The levels

WCAG 2 uses these minimum ratios. Normal text is about 16px. Large text here is 24px and bold, which matches the large-text rule. AA is the usual target for body text. AAA is stricter.

The math uses the WCAG relative luminance formula. Nothing is uploaded.
