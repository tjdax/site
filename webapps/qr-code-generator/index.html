Tips for a code that scans

Keep a dark code on a light background, and leave the quiet zone at 4 modules. Higher error correction lets the code survive scratches or a logo on top, but the code gets denser. For printing, download the SVG; it stays sharp at any size.

Wi-Fi codes let a phone join your network without typing the password. Email and phone codes open a new message or call.
