Image Metadata

Open a JPEG or PNG to see the camera, date, and location stored inside it, then save a copy with that information removed.

Drop an image here, or use Open image. It stays on this device.

What gets removed

JPEG files lose EXIF (camera, date, GPS), XMP, IPTC, and comments. PNG files lose text notes, EXIF, and the stored modification time. The compressed picture itself is kept, so the pixels are not recompressed.

Other formats are left unchanged. Nothing is uploaded.
