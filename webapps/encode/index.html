Encode & Hash

Base64, URL encoding, SHA-256, and UUIDs. Your text stays in this browser.

Result 

    

    

      
What each one does

      
Base64 turns any text, including letters outside English, into a safe ASCII string and back. URL encode escapes spaces and punctuation so they can sit inside a link. SHA-256 is a one-way fingerprint: the same text always gives the same hash, and the hash cannot be turned back into the text. New UUID makes a random id in the form 8-4-4-4-12.

      
Nothing is sent to a server.
