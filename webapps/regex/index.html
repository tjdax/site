Regex Tester

Type a pattern and some text. Matches and groups update as you type.

    How to use it

    The pattern is a JavaScript regular expression. Ignore case adds i. Multiline makes ^ and $ match each line. Groups in parentheses are listed under the highlighted text.

    A pattern that matches an empty string is skipped forward so the page does not hang. Very long text is cut at 20,000 characters.

    Nothing is sent to a server.
