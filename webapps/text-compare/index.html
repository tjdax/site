Text Compare

Paste two versions and see which lines were added or removed. The text never leaves this page.

How to read it

A green line was added in the changed text. A red line was removed from the original. Lines that match stay plain. Comparison is by whole line, and it updates as you type.

Nothing is sent to a server. Very long texts are compared using the first 800 lines of each side.
