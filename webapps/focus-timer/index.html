Focus Timer

Set a countdown and, if you want, a steady background sound. The sound is generated here. Nothing is downloaded or uploaded.

25:00

Background sound

The sounds

White noise is an even hiss. Brown noise is lower and softer. Rain is that hiss with short drops mixed in. A chime plays when the timer reaches zero. Changing the length stops the current countdown, so press Start again.

Audio is created with the Web Audio API in this tab. No sound file is fetched.
