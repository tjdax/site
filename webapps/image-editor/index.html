Save

Download saves the selected box. Width and height are the file's resolution, and they start equal to the box, so an 800 × 600 box saved at 800 × 600 is exactly those pixels. Choose JPEG or WebP to use quality. PNG is lossless.

How cropping works

The box is measured in the image's own pixels, not screen pixels. Arrow keys nudge it by 1 pixel, and Shift plus an arrow key nudges by 10. Apply crop cuts the picture down so you can crop again. Reset brings the original back.

Quality is the JPEG or WebP compression. A lower number makes a smaller file. JPEG has no transparency, so empty pixels are filled with the background color. Rotate and flip apply to the whole image, and the box keeps covering the same pixels.
