TJDAX / AI lab / apple

apple

apple is a value-network agent for a guideline falling-block puzzle. tjdax trained it. This is the first model from that run. Development closed on 10 October 2026, and training is not running.

Close of development

The checkpoint that closed the run was written at 16:17:49 local time on 10 October 2026. Recorded training time on that file is 4,413 seconds, which is 1 hour 14 minutes, including an earlier session from the same day that was resumed from disk. The process was then stopped. Generation 10,212 had started and was not saved.

tjdax ended the project there. More generations were not run. Public open-source weights for this kind of puzzle already exist, and this network was not trained to replace them. The useful record is the measurement below, not another night of the same loop.

What the hour produced

The run stood up a complete training loop and kept a checkpoint after every generation.

  • Rules engine. A Rust engine for the guideline falling-block rules: seven pieces, hold, rotation kicks, line clears, attack, and incoming garbage. The same engine supplied the legal placements to the learner.
  • Network. A value network trained from scratch with NumPy and Adam. It has 306 observation inputs, one hidden layer of 64 ReLU units, and one output that predicts remaining attack. PyTorch was not used. The optimizer state was stored with the weights, so a reboot continued the same update rather than resetting Adam.
  • Self-play. Eight worker processes, one game each per generation, then one value update on the main process. The core cap was 8 of 16 logical CPUs, and the process priority was below normal so the machine stayed usable.
  • Move choice. Search looks one ply ahead, over every legal placement. The score adds attack sent and 0.35 times lines cleared, adds 0.4 times a z-scored value estimate, and subtracts a penalty for holes, stack height, and topping out.
  • Ladder. One duel per generation against a fixed greedy heuristic. Both sides receive the same piece sequence. The piece limit is 40. A win counts as 1 only when the heuristic tops out and apple does not. A loss counts as 0 when apple tops out. If both survive the limit, the game is a draw and counts as 0.5.
  • Elo. The heuristic is anchored at 1000. Each evaluation updates apple with K = 24.

Final checkpoint

  • Generation. 10,211 completed. 10,212 was in progress and was discarded.
  • Recorded time. 1 hour 14 minutes.
  • Self-play games. 81,696, including games restored when training resumed.
  • Afterstate samples. 2,776,545 positions used to train the value output.
  • Value updates. 8,682.
  • Workers. 8.
  • Network shape. 306 × 64 × 1.
  • Best attack per piece. 0.250, the highest generation in the run. Attack per piece is attack sent divided by pieces placed.
  • Attack per piece at generation 10,211. 0.163. Later generations did not lock in a level above the early peak.
  • Elo. 970.4. The heuristic stays at 1000, so apple finished slightly behind that opponent.
  • Evaluations. 8,682.
  • Wins / losses / draws. 8 / 525 / 8,149.
  • Mean score. 0.4702. A win is 1, a draw is 0.5, and a loss is 0, averaged from the first evaluation.

How to read that score

Almost every ladder game was a draw. 8,149 of 8,682 evaluations ended with both sides still alive after 40 pieces, so neither player proved it could kill the other inside the limit. Draws sit on 0.5 and barely move an Elo that is already near 1000. The decided games are the informative ones: apple won 8 and lost 525. When someone topped out, it was usually apple.

The mean score of 0.4702 is that lifetime average. It stays near one half because of the draws, and it sits under one half because of the losses. It is a poor gauge of a single generation. Elo is the running rating, and attack per piece is the self-play attack of the latest generation. Neither one was climbing through the close of the run.

Survival inside self-play was usually 1, which means the eight games of a generation reached the piece limit without topping out. That is endurance under a short cap, not a win on the ladder. The T-spin rate in late generations was usually 0.

Marks during the run

  • Generation 0. Training started.
  • Generation 8. The first T-spin clear appeared in self-play.
  • Generation 596. One generation reached 0.20 attack per piece.
  • Generation 672. The first win against the heuristic.

The marks that were defined and not reached are 0.50 attack per piece and 1.00 attack per piece. The best generation stopped at 0.250.

What the result is

apple is evidence that tjdax could train a small value network on the lab engine, resume it after a restart, and write down the ladder score. It is not evidence that the network plays better than the heuristic it was measured against, and it is not a claim about the open-source weights that already exist for this puzzle. Those weights are the reason this training stopped. The numbers on this page are the whole result.
